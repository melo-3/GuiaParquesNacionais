# Guia de Parques Nacionais
Projeto da disciplina de desenvolvimento mobile feito em react native.

## Sobre
Catálogo com os principais parques nacionais do Brasil, um por região, com nome, descrição e tag de região.

## Tecnologias utilizadas
- React Native
- Expo

## Identidade Visual
Paleta de cores gerada no Adobe Color, com tons que rementem à natureza
